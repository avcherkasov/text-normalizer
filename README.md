# text-normalizer

## Требования
- maven 3.9.11 или выше
- java 25 или выше

## Задача

Необходимо обратывать входящие данные по cardholder-у 
для возможной обработки на серверной стороне из предоставленных списков для блокировок

Так как чётких или вообще каких-либо требований нет, будем продумывать на ходу

Тестовые данные
- Петров Василий Васильевич
- Halif Alibaba Alibabaevich
- Ms Bell Curves
- Mr Smith

В БД будет записей при возможных перестановках (вариациях) без повторений, которые вычисляются как факториал от количества слов: 
- 3! = 3*2*1 = 6
- 5! = 5*4*3*2*1 = 120
- 6! = 6*5*4*3*2*1 = 720 (вариант вполне возможный, например, с двойными фамилиями)

Если нужен выбор результата и нужно оптимизировать, то списки не очень подходят

При использовании списков будем проходить по каждому элементу при поиске
```
List<String> cardholders; // O(n)
```

Можно воспользоваться Set<String>, чтобы сразу получать результат без перебора
```
Set<String> cardholders = Set.of("Halif", "Bell"); // O(1)
cardholders.contains("Halif");
```
